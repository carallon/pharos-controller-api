RDM operations such as :doc:`Discovery <../../http-api/rdm-discovery>`, :doc:`Get <../../http-api/rdm-get>` and :doc:`Set <../../http-api/rdm-set>` commands can be initiated via the HTTP API. Results from these operations are asynchronous so are fed back via the WebSocket API.

Discovery results are fed back via :doc:`rdm-discovery`.
